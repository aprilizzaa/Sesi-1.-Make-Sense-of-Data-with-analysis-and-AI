# 📊 Sesi 1: Make Sense of Data with Analysis and AI

Proyek ini berisi Executive Dashboard & Interactive Simulator berbasis web untuk studi kasus analisis data bisnis dan kecerdasan buatan (AI) pada PT Maju Bersama, yang disusun berdasarkan materi kuliah praktisi oleh **Andria Arisal, ST., M.Eng.** (Peneliti Senior BRIN).

---

## 📌 Ringkasan Studi Kasus

PT Maju Bersama mengalami anomali kinerja bisnis selama 2 tahun terakhir:
- **Sales Revenue**: Naik **+33.7%**
- **Net Profit**: Menurun **-14.0%**
- **Account Receivables (Piutang)**: Membengkak hingga **+300%**
- **Operating Cash Flow**: Berkurang **-51 Juta**

Aplikasi web ini menyajikan visualisasi data, analisis akar masalah berbasis kerangka kerja **CRISP-DM**, serta simulator prediksi risiko kredit dengan pendekatan **AI Human-in-the-Loop**.

---

## 🚀 Fitur Utama Web Dashboard

- **Executive Financial Metrics**: Ringkasan indikator kinerja keuangan utama secara visual.
- **CRISP-DM Pipeline**: Penjelasan alur pengolahan data mulai dari *Business Understanding* hingga *Model Validation*.
- **4 Levels of Data Analytics**: Klasifikasi analisis mulai dari *Descriptive*, *Diagnostic*, *Predictive*, hingga *Prescriptive Analytics*.
- **Interactive Credit Risk Simulator**: Simulator interaktif untuk menguji skor risiko keterlambatan invoice dan menentukan keputusan intervensi manajerial secara *real-time*.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & Tailwind CSS**: Tampilan antarmuka antarmuka modern, responsif, dan rapi.
- **Alpine.js**: Komponen interaktif untuk simulasi risiko kredit.
- **FontAwesome**: Ikon visual yang intuitif.
